# Trợ lý AI học tập và lịch trình

Bài tập lớn môn Trí tuệ nhân tạo (Application Track). Hệ thống gom email, đề bài và giáo trình thành lịch học có nhắc nhở, kèm hỏi đáp có trích dẫn trang.

| Module | Phụ trách |
|---|---|
| A — Hỏi đáp tài liệu qua API | Nam |
| B — Trích xuất yêu cầu bài tập | Trường |
| C — Lập lịch & nhắc nhở, khung giao diện | Long |
| D — Email & bảo mật | Hoàng Minh |

## Quy trình làm việc

- Đặc tả theo [spec-kit](https://github.com/github/spec-kit): `.specify/` chứa template, `specs/` chứa đặc tả từng tính năng.
- Mỗi người một nhánh, merge vào `main` qua pull request có người khác review.
- Không commit `.env`, dữ liệu thật, email thật.

Hướng dẫn cài đặt và chạy sẽ được bổ sung khi có khung ứng dụng.
